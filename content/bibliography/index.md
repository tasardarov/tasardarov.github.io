## BibTeX

BibTeX - это формат для хранения библиографических записей, используемый в LaTeX.

```bibtex
@article{example2026,
  author = {Сардаров, Т.},
  title = {Название статьи},
  journal = {Журнал},
  year = {2026}
}
```
